# 動力提醒信(Motivation Mailer)

## 想法由來

會做這個工具,是因為使用者有一段時間處於混亂、沒動力、憂鬱的狀態。使用者自己清楚知道「人只能靠自己」這件事,但這個認知在情緒低落的當下常常不會自動跳出來提醒自己——道理知道,但陷進去的時候想不起來。

這個工具的目的,是做一個**外部觸發器**:在固定時間跟不固定時間,寄簡短的提示語到自己的Gmail,補上「情緒低落時,認知提醒不會自動出現」這個空隙。

**這是輔助工具,不是取代求助**——如果低落感是持續性的,找人聊聊(朋友或專業資源)跟這個工具不衝突,可以並存。

## 目的與需求

- 訊息內容:多句輪流亂數抽,不要固定同一句,避免看久了麻痺、失去提醒效果。
- 發送時間分兩種:
  - **固定時間**:使用者自己指定的鐘點,每天準時觸發,目前已設定4個。
  - **不固定時間**:時間點不固定,避免因為「知道信什麼時候會來」而提前有心理準備、降低突襲提醒的效果。範圍限制在:
    - 平日(一~五):17:00~22:00(下班後)
    - 假日(六、日):06:00~22:00(整天)
  - 兩種時間各自平均約**4封/天**,不要讓不固定時間的部分因為窗口比較長就變得比固定時間還多。
- **暫停機制**:假日有時候是真心想放鬆、不想被打擾,需要一個「今天先不要」的開關,不用每次都跑去刪排程。
- **全部停止機制**:未來如果不想再用這個工具了,要能一鍵把所有排程清掉,不用一個一個去工作排程器裡找。
- 執行環境是不關機的電腦(公司電腦),所以用Windows工作排程器做本機排程,不需要處理電腦睡眠喚醒的問題。

## 檔案說明

| 檔案 | 用途 |
|---|---|
| `01.暫停今天.bat` | 雙擊暫停「今天」的所有提醒信(固定+不固定都會被擋),隔天自動恢復,不用手動解除 |
| `02.設定排程.bat` | 問答形式的排程設定精靈,依序輸入想要的固定提醒時間(HH:MM),並可選擇是否一併設定不固定時間排程 |
| `03.全部停止.bat` | 找出所有`MotivationMailer`開頭的Windows排程並全部刪除,之後要重新用要再跑一次`02` |
| `send_reminder.py` | 核心寄信邏輯:檢查暫停旗標→判斷時間窗口/機率(或固定時間、測試模式跳過這步)→亂數抽訊息→寄信 |
| `setup_schedule.py` | `02.設定排程.bat`背後呼叫的實際程式,用`schtasks`指令建立Windows排程 |
| `stop_all.py` | `03.全部停止.bat`背後呼叫的實際程式 |
| `write_pause.py` | `01.暫停今天.bat`背後呼叫的實際程式,把今天日期寫進`pause.flag` |
| `messages.txt` | 提示語清單,一行一句,可以隨時自己編輯增減 |
| `config.example.json` | 設定檔範本(進版控),說明需要哪些欄位 |
| `config.local.json` | 實際的Gmail帳號/應用程式密碼設定檔(**不進版控**,`.gitignore`已擋住) |
| `pause.flag` | 暫停旗標,存今天的日期,`01`寫入、`send_reminder.py`讀取判斷 |

## 使用說明

### 第一次設定

1. 到Google帳號([myaccount.google.com/security](https://myaccount.google.com/security))開啟兩步驟驗證,產生一組「應用程式密碼」(16碼,跟平常登入密碼不同)。
2. 打開`config.local.json`,填入`gmail_address`(你的Gmail帳號)、`gmail_app_password`(剛才產生的應用程式密碼)、`recipient`(通常跟`gmail_address`填一樣,寄給自己)。**這個檔案不要分享出去或貼上網,裡面是可以直接寄信的憑證。**
3. 雙擊`02.設定排程.bat`,依提示輸入想要的固定提醒時間(格式`HH:MM`,例如`08:00`),輸入完直接按Enter結束;接著會問要不要一併設定「不固定時間」排程,選`y`就會建好。
4. 如果雙擊後出現「拒絕存取」之類的錯誤,右鍵`02.設定排程.bat`選「以系統管理員身分執行」再試一次。

### 日常使用

- 想暫停今天的信:雙擊`01.暫停今天.bat`,隔天不用做任何事會自動恢復。
- 想調整提示語:直接編輯`messages.txt`,一行一句,存檔即可生效,不用重新設定排程。
- 想新增/更改固定提醒時間:重新跑一次`02.設定排程.bat`,新的時間點會另外建立排程(不會覆蓋掉舊的),如果要拿掉某個舊時間點,要自己去Windows「工作排程器」裡手動刪除對應名稱的項目,或整個用`03`清空後重新設定。
- 想調整「不固定時間」的窗口範圍或平均封數:要改`send_reminder.py`裡的`WEEKDAY_WINDOW`、`WEEKEND_WINDOW`、`TARGET_RANDOM_EMAILS_PER_DAY`這幾個常數,改完不用重新排程,下次排程觸發時就會用新的邏輯。
- 不想再用了:雙擊`03.全部停止.bat`,會清空所有排程。

### 驗證/除錯

- 測試邏輯但不真的寄信:在這個資料夾開終端機執行 `python send_reminder.py --dry-run --force`(略過時間窗口判斷,直接印出會寄的內容)。
- 測試邏輯是否正確判斷現在在不在窗口內:`python send_reminder.py --dry-run`(不加`--force`,照正常邏輯跑一次判斷)。
- 想確認目前現有哪些排程:Windows搜尋「工作排程器」打開,或指令`schtasks /query /fo list | findstr MotivationMailer`。
